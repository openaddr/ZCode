# Triage labels(GitHub)

沿用五个规范角色,标签名即角色名,已在 openaddr/ZCode 创建为 GitHub label:

| 标签 | 含义 |
| --- | --- |
| `needs-triage` | 未分诊,等待判定处理路径 |
| `needs-info` | 需要补充信息才能继续 |
| `ready-for-agent` | 可交给 agent 实施 |
| `ready-for-human` | 需要人处理或决策 |
| `wontfix` | 不做(沿用 GitHub 默认标签) |

无重命名、无自定义覆盖;生命周期状态(进行中/完成)用 Issue 原生 open/close 与 assignee 表达,不另设标签。
